# Install packages and test their APT lifecycle

This fixture installs checksum-pinned, existing Debian packages into an official
Debian root filesystem. It never builds or repacks a Debian package.

The native AMD64 and ARM64 CI jobs use the declared Debian build container.
Bubblewrap is a separate, checksum-pinned executable. It needs a root build
container with `CAP_SYS_ADMIN` and `CAP_NET_ADMIN` to create private mount, process and network
namespaces and initialize the private loopback interface. Package scripts do not
receive either of these capabilities. The container does not mount the Docker socket. Verification tools
installed with APT are recorded by resolved version in the test receipt; they
are not part of the checksum-locked image inputs.

`validate.py` audits the Bazel action graph before building `//:configured`, then
rejecting DEB output files and known packaging commands. It binds the installer
receipt to the locked base and package hashes, confirms a repeated build leaves
the outputs unchanged, then checks the filesystem before running any validation
APT transaction:

- The APT download directory retains its non-root `_apt` owner.
- CA certificate configuration, bundle and OpenSSL hash links.
- Vim and Less command alternatives.
- The `uuidd` system user and group created by its installation script.
- A newly installed shared library in the loader cache, generated by the
  `ldconfig` trigger, and no unprocessed dpkg triggers.

It then installs hello `2.10-3`, upgrades it to `2.10-5`, removes it, removes and
purges Vim Tiny while checking configuration-file preservation, and removes Less
while checking that More becomes the pager. Each transaction uses the installed
image's APT/dpkg and a local repository of verified DEBs with networking disabled.
`dpkg --audit` and `apt-get check` must pass throughout.

The package lock records the original URLs and SHA256 values. Updating that lock
is a deliberate input change; a successful test is not a guarantee for every
possible maintainer script or future package version.
